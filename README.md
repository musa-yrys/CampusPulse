# CampusPulse

CampusPulse — студенттік клубтар мен кампус іс-шараларына арналған ASP.NET Core MVC жобасы. Жоба іс-шара каталогын, санат пен мәтін бойынша іздеуді, тіркелуді және орын толған кезде күту тізімін ұсынады. Ұйымдастырушы панелінен оқиға жариялап, өшіруге болады.

## Технологиялар

- ASP.NET Core MVC (.NET 8)
- Entity Framework Core 8, SQL Server
- Razor Views және адаптивті CSS

## Іске қосу

1. SQL Server LocalDB орнатылғанын тексеріңіз.
2. `CampusPulse.sln` шешімін Visual Studio-да ашыңыз.
3. `CampusPulse` жобасын іске қосыңыз. Деректер қоры бірінші іске қосылғанда автоматты түрде жасалып, демо іс-шаралармен толтырылады.

Қосылым жолы `appsettings.json` ішінде. Өз SQL Server инстансыңызға сәйкес өзгертіңіз.

## Негізгі мүмкіндіктер

- Алдағы іс-шараларды қарау, санатпен сүзу және іздеу
- Іс-шараның орны, уақыты және бос орын санын көру
- Email арқылы тіркелу, қайталама тіркелуді болдырмау
- Сыйымдылық толса, қатысушыны күту тізіміне қосу
- Іс-шара жариялау және басқару

Барлық бет қазақ тілінде. Демода нақты студент деректері жоқ.
